# UI-2 Project 🎨

This is my second UI project built using **HTML & CSS**.  
The main focus of this project was to practice **CSS positioning** and layout techniques to create a clean and structured interface.

---

## 🚀 Features
- Built entirely with HTML & CSS
- Demonstrates use of **relative, absolute, and fixed positioning**
- Organized layout with styled components
- Beginner-friendly structure for learning UI design

---

## 🎯 Purpose
The goal of this project was to:
- Strengthen my understanding of CSS positioning
- Learn how elements interact in different layout contexts
- Improve my UI design and front-end development skills
